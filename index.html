Scarica APK — Android Scarica IPA — iOS
🤖
Android — APK
  1. Scarica il file WordsFever.apk
  2. Vai in Impostazioni → Sicurezza
  3. Attiva Origini sconosciute (o "Installa app sconosciute")
  4. Apri il file APK dal gestore file e tocca Installa
iOS — IPA (sideload)
  1. Scarica il file WordsFever.ipa
  2. Installa AltStore o Sideloadly sul PC
  3. Collega iPhone via USB e trascina il file IPA
  4. Fidati dello sviluppatore in Impostazioni → Generali → VPN e gestione dispositivo

⚠️ Richiede Apple ID gratuito. Valido 7 giorni senza Apple Developer Account.
