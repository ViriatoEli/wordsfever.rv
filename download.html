Installa su Android
~30 secondi • Android 6.0+
  1. 1
    Scarica il file WordsFever.apk cliccando il bottone qui sopra.
  2. 2
    Apri le Impostazioni del telefono → Sicurezza (o App su Android 8+).
  3. 3
    Attiva "Origini sconosciute" o "Installa app sconosciute" per il browser o file manager.
  4. 4
    Apri il file APK dalla cartella Download e tocca Installa. Fatto!
Installa su iPhone
Via AltStore o Sideloadly • iOS 14+
  1. 1
    Scarica il file WordsFever.ipa cliccando il bottone qui sopra.
  2. 2
    Sul tuo PC o Mac, scarica e installa AltStore o Sideloadly (entrambi gratuiti).
  3. 3
    Collega l'iPhone al PC con cavo USB, apri AltStore/Sideloadly e trascina il file .ipa nell'app.
  4. 4
    Sull'iPhone: Impostazioni → Generali → VPN e gestione dispositivo → tocca il profilo e premi Fidati.
  5. 5
    Apri Words Fever dall'home screen. Se chiede di "Consentire", premi Consenti.
⚠️ Richiede Apple ID gratuito. Il certificato dura 7 giorni senza Apple Developer Account (99€/anno). Basta reinstallare seguendo la stessa procedura.
